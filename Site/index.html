Good browser design is mostly knowing what not to keep alive.

Most browsers keep every tab ready whether you looked at it five seconds ago or five days ago. Browsemium lets you choose the live-tab limit and sleep schedule; sleeping tabs reload when you return.

Memory saver, on your terms

Choose how long background tabs stay live and how many pages to keep loaded. A tab may reload when you come back.

WebKit, used deliberately

Inactive WebViews are released when tabs sleep, profiles change, or macOS reports memory pressure.

Numbers we can stand behind

Browsemium reports the memory it can measure. It does not invent per-tab WebKit usage or blocked-request counts.

The assistant works beside the page. You stay in control.

Use ChatGPT, Claude, Gemini, Grok, or Ollama beside the page you are reading. When enabled, Browsemium can prepare a sanitized URL and bounded page text for your message. Screenshots, selections, and files are attached only when you choose them.

Install Browsemium.

One command in Terminal. The installer checks the release manifest, SHA-256 checksum, DMG integrity, and the app's signature, sandbox, and architectures before copying anything; updates leave your profiles and tabs in place.

curl -fsSL https://browsemium.vercel.app/install.sh | bash

Preview build. Browsemium is ad-hoc signed and not notarized by Apple yet, so macOS may block the first launch. If it does: System Settings → Privacy & Security → Open Anyway.

Questions, answered plainly.

Is Browsemium faster than Chrome?

Browsemium does not claim to render pages faster. It brings your browsing and AI workflows into one place, and lets you unload idle background tabs on a schedule you choose.

How does memory saver work?

Choose how long background tabs stay live and the maximum number to keep loaded. A sleeping tab reloads when you return. Browsemium reports the app memory it can measure; WebKit does not expose memory per tab.

What can the AI receive?

When enabled, a message can include the page title, a sanitized URL, and bounded readable page text. Screenshots, selections, and files are never attached automatically: you choose them for a message and review them before sending.

What comes over when I switch browsers?

The importer previews compatible profiles, bookmarks, history, passwords, search settings, and sessions before writing anything. Cookies, extensions, and engine-specific site data are not copied.

Do I need an API key?

No. Use ChatGPT, Claude, Gemini, or Grok with the web subscriptions you already have. API keys are optional and stored in the macOS keychain. Ollama can run locally on this Mac.

macOS says Browsemium can't be opened — now what?

Preview builds are ad-hoc signed and not notarized by Apple yet, so Gatekeeper may block the first launch. Open System Settings → Privacy & Security and choose Open Anyway next to Browsemium. The installer verifies the checksum, signature, sandbox, and architectures before anything is copied, and it never removes quarantine attributes — the choice to open stays yours. Developer ID signing and notarization return with the stable release.
