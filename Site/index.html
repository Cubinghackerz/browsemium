A macOS browser built around the AI you already use.

What it does, specifically.

AI beside the page

Open ChatGPT, Claude, Gemini, or Grok in the dock and keep your subscriptions. Attach the selection, the readable page text, or a screenshot of the current tab. Each one is captured only when you ask.

Prefer API access? Add your own key for any of the four providers. Keys live in the macOS keychain and go only to that provider.

Nothing sent by accident

Every attachment is reviewed in a sheet that names the destination and shows exactly what will be shared. The assistant never clicks, types, or submits anything for you. It suggests; you decide.

Lower memory, honestly measured

Background tabs are unloaded after an idle period you choose, with a ceiling on how many stay loaded. The trade-off is stated in the app: pages reload when you return to them. Memory saver, the idle window, and the ceiling are all yours to set.

Ads and trackers blocked

WebKit content rules compiled from Browsemium's own list, applied to every tab. WebKit does not report how many requests it stopped, so the app shows rule state rather than inventing a count.

Passwords that stay yours

Saved logins live in your keychain. Browsemium fills one only after you pick it, only on HTTPS, only for the matching site. It never submits the form.

Your data comes with you

Import bookmarks, history, reading list, default search engine, and passwords from Chrome, Brave, Edge, Vivaldi, Arc, and Chromium, plus bookmarks and history from Firefox and Safari. A preview shows exactly what was found before anything is written.

Small things that matter daily

Horizontal tabs you can drag to reorder, session restore, find in page, zoom, print, a bookmarks bar, a downloads indicator with live progress, private browsing, per-site permissions, and quick search-engine switching from the address bar, including !d, !b, and !br for a one-off search.

What it won't claim.

  • It is not faster at rendering pages. Browsemium is WebKit. It is faster to get to an answer, and that is a different sentence.
  • It does not measure memory for you in the abstract. The app reports its own real footprint and whether a tab holds a web view. WebKit renders in separate processes, so per-tab memory is not measurable, so it is not shown.
  • It never shows a blocked-item count. WebKit does not expose one, and a made-up number would be a lie told in a progress bar.
  • It does not sync, sign you in, or phone home. There is no account system and no telemetry, by design rather than by setting.
  • It cannot move every password. Firefox keeps passwords in its own encrypted key database and Safari keeps them in your iCloud Keychain. Chromium-family browsers can be read once you allow keychain access; the others cannot, and the app says so before you start.
  • It is macOS only. macOS 14 or newer, Apple silicon or Intel.

Install.

  1. Download the latest DMG from Releases, or build from source below.
  2. Drag Browsemium into Applications.
  3. Open it and pick your search engine, appearance, privacy level, and whether the assistant is on.
  4. Import your bookmarks, history, and passwords from another browser if you like, with a preview first.
# Build from source
git clone https://github.com/Cubinghackerz/browsemium
cd browsemium

# Full Xcode and XcodeGen are required
xcodegen generate --spec project.yml
xcodebuild -project Browsemium.xcodeproj \
  -scheme Browsemium -configuration Debug build

The test suite runs with swift test --package-path Packages/BrowsemiumKit.
