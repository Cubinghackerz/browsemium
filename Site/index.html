Profiles that actually separate your life.

Every profile gets its own cookies, logins, history, bookmarks, tabs, and passwords. Sign into work tools in one profile and personal accounts in another, on the same Mac, without a single crossover.

When you import from Chrome or Firefox, Browsemium finds every profile in that browser and can turn each one into its own profile here, named the way you named it there.

The assistant lives in the browser, not on top of it.

ChatGPT, Claude, Gemini, and Grok open in the dock beside your page. Select text, capture a screenshot, or share the readable page, review exactly what will be sent, then send it. Drag a capture straight into the chat when you prefer.

  • Right-click a selection and ask about it without leaving the page.
  • Ollama runs entirely on this Mac, with no key and no account.
  • The assistant never clicks, types, or submits, so every action stays yours.

Background tabs get unloaded, and it tells you.

Browsemium does not claim to render pages faster than Chrome. It claims to stop wasting memory on tabs you have not looked at in an hour. Idle tabs are unloaded on a schedule you control, with a ceiling on how many stay live.

The trade-off is stated plainly in the app: a tab you return to reloads. WebKit does not report per-tab memory, so Browsemium never shows a number it cannot verify.

Blocking that is honest about what it blocks.

Ads and trackers are blocked with compiled WebKit content rules, on by default and configurable. WebKit does not expose a blocked-request count, so the app reports rule state instead of inventing a number that looks impressive.

Local history and bookmark suggestions in the address bar, search-engine switching, and one-off !g !d !b !br prefixes are all there too.

D doubleclick.net blocked
F fonts.gstatic.com allowed

Bring everything over, then leave the old browser behind.

Chrome, Brave, Edge, Vivaldi, Arc, Chromium, Firefox, and Safari are all detected. Import bookmarks with their folders, history, Safari's reading list, your default search engine, and Chromium-family passwords into the macOS keychain.

Firefox and Safari passwords are not importable, and the app says why instead of failing quietly. Cookies are never imported. Nothing is uploaded, and nothing is removed from the browser you came from.

Install from the terminal

Browsemium is signed ad-hoc rather than with an Apple Developer ID, so a browser-downloaded copy would be refused once by Gatekeeper. Both paths below fetch the release without a quarantine flag, verify it, and install it — no warning, no extra clicks.

Recommended

Terminal installer

Fetches the release with curl, verifies its SHA-256 against this site, installs to Applications. No Gatekeeper prompt, because nothing marks the file as a browser download.

curl -fsSL https://browsemium.vercel.app/install.sh | bash

Homebrew

One command for people who already live in the terminal. The cask is updated by the release workflow on every version.

What Browsemium does not claim

Rendering speed is not claimed. Browsemium gets you to an answer sooner; it does not claim to paint pages faster.

Per-tab memory is not reported, because WebKit does not expose it.

Blocked-item counts are not shown, because WebKit does not report them; the app shows rule state instead.

There is no account and no sync. Browsing data stays on this Mac.

Questions

Why does macOS warn about the DMG?

The build is signed ad-hoc instead of with a paid Apple Developer ID, so Gatekeeper has no certificate to check it against and refuses the first launch. It is Apple's response to a missing certificate, not a malware detection.

The terminal installer and the Homebrew cask avoid the prompt entirely. Notarization is the permanent fix and is planned once a Developer ID is in place.

Where does my data live?

In Browsemium's own folder under Application Support, one database per profile, plus WebKit's data store per profile. Passwords and API keys live in the macOS keychain. Nothing is uploaded anywhere unless you send it to a site or a provider you chose.

How do updates work?

Sparkle checks a signed feed once a day and verifies an EdDSA signature before installing anything. Updates carry no quarantine flag, so they install without a Gatekeeper prompt. You can also check manually from the Browsemium menu.

Can the AI click or type for me?

No, by design. The assistant can read the page text, a selection, or a screenshot when you ask it to, and it is reviewed before sending. It never clicks, types, submits, or runs anything on a page, and it will say so if you ask it to.

Do I need API keys?

No. The dock can load ChatGPT, Claude, Gemini, and Grok websites with your existing subscriptions. API keys are optional, stored in the macOS keychain, and only needed if you prefer the API. A local Ollama server needs no key at all.
