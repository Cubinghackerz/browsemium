Why it feels lighter

Good browser design is mostly knowing what not to keep alive.

Most browsers keep every tab ready whether you looked at it five seconds ago or five days ago. Browsemium gives you a simple ceiling: keep the tabs you are using live, unload the rest, and reload them when you return.

↘

Memory saver you can explain

Background tabs can be suspended or hibernated on a schedule you control. The trade-off is visible: a tab may reload when you come back.

◌

WebKit, kept purposeful

Live WebViews are released when tabs sleep, the profile changes, or memory pressure arrives. The app does not keep a hidden browser farm warm.

✓

Honest about numbers

System memory is measured where macOS exposes it. Per-tab WebKit memory and blocked-request counts are not invented just to make a chart look good.

AI, without another app window

The assistant follows your page, not the other way around.

Use ChatGPT, Claude, Gemini, Grok, or Ollama beside the page you are reading. Send through the provider’s own composer, with sanitized metadata, bounded readable text, and a full-page screenshot prepared automatically when page context is enabled.

  • One composer. No duplicate input bar under the provider.
  • Your send stays yours. Browsemium prepares context; it never clicks around the site for you.
  • Context is bounded and visible. Automatic page context is opt-out; selections and extra files remain one-message choices.
  • One-tap page actions. Summarize, extract key points, or explain a selection without composing a prompt first.

Questions, answered plainly.

Is Browsemium actually faster than Chrome?＋

It does not claim to paint web pages faster. It is designed to get you to useful work faster—with AI beside the page, fewer profile boundaries to manage, and background tabs that can unload when they are idle.

How does it use less memory?＋

Memory saver unloads background tabs according to the schedule and live-tab limit you choose. A tab can reload when you return to it. Browsemium reports the app footprint it can measure and does not pretend WebKit exposes per-tab memory.

What does the AI receive automatically?＋

When enabled, web-provider messages include the current page title, a sanitized URL, readable page text when the page provides it, and a bounded full-page screenshot uploaded through the provider's own verified file input. You can turn automatic context off in Settings, and extra selections/files remain explicit.

Can I move from Chrome without losing everything?＋

The migration assistant supports the compatible parts of profiles, bookmarks, history, passwords, search settings, and sessions. It reviews the result first. Cookies, extensions, and browser-engine-specific site data are not copied, and Chrome is never silently modified.

Do I need an API key?＋

No. Use ChatGPT, Claude, Gemini, or Grok with the web subscriptions you already have. API keys are optional and stay in the macOS keychain. Ollama runs locally on this Mac.
