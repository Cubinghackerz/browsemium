# Browsemium 2.0.2

This maintenance release makes Web AI context predictable and removes the
automatic screenshot upload path.

## Assistant

- Normal Web AI messages automatically include only sanitized page metadata and
  bounded readable page text when the setting is enabled.
- A normal Send never creates or uploads a screenshot. Use Capture, Full page,
  or Add file when an image or document should be attached explicitly.
- Updated the assistant labels and notice so the automatic-context behavior is
  clear before a message is sent.

## Reliability and security

- Added a regression guard that keeps automatic Web AI context text-only.
- Kept explicit uploads inside Browsemium's private staging boundary and left
  provider navigation and stale-send protections enabled.

The web assistant prepares context and uploads explicitly selected files, but it
does not control the browser or take actions on the user's behalf.
