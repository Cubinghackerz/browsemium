# Browsemium 2.0.1

This maintenance release makes the AI dock and update path safer and more
reliable.

## Assistant

- Web-provider messages now use the provider's own composer with no duplicate
  native input bar underneath it.
- Page context is prepared automatically when enabled: sanitized metadata,
  bounded readable text, and a full-page screenshot are sent with the user's
  message.
- Screenshots and staged files are uploaded through the provider's verified
  file input. Supported files are size-limited, validated, and retained for a
  retry if a send fails.
- Provider navigation, reloads, and overlapping sends are guarded so stale
  context cannot be attached to a newer page and a failed send does not lose
  the user's draft.

## Reliability and updates

- Release builds continue to pass launch and crash-recovery gates before a DMG
  is published.
- The release workflow now refreshes the landing page's version and checksum
  alongside the signed Sparkle appcast, so the public download page cannot
  advertise an older build after an update.

## Honest limits

- The web assistant can prepare context and upload files, but it does not click,
  type, navigate, download, or otherwise control the browser.
- DMGs remain ad-hoc signed until a Developer ID certificate and notarization
  credentials are configured; macOS may require the one-time Open Anyway step.
