# Browsemium 2.2.0

A preview release. It is ad-hoc signed and **not notarized**. On another Mac,
macOS asks you to allow it once in System Settings → Privacy & Security →
Open Anyway.

Most of what is new is opt-in and off by default. A feature's data is used only
after you turn that feature on.

## Before you update

- The first launch upgrades your profile database in place (migrations v12 to
  v19). If you may want to go back to an older version, back up your profiles first.
- There is still no Browsemium account, no product telemetry, and no cloud sync.
- This release makes no speed or memory claims.

## Sites and extensions

- Choose Allow, Ask, or Deny for each extension on each site, in Settings →
  Extensions or from the site shield. Deny wins over broader permissions and
  over prompts answered after the tab has moved on. A change applies on the
  next page load, so reload a page that is already open.
- Site routing sends a site to a space. The tab moves with a notice and an
  Undo. Private windows, previews, background and pinned tabs, and split view
  are never moved. A locked space asks first.
- Separate groups keep their own cookies, logins, and site data, so one site
  can hold two accounts. Extensions do not run in separate groups.
- Page tweaks: your own CSS for a site, with a live preview. CSS that loads
  anything from the network is refused. "Write CSS" can draft a tweak on this
  Mac with Apple Intelligence. It sees the page's structure, not its text, and
  nothing is saved until you preview it.
- Tracking parameters are removed from links at Balanced and Strict, never from
  sign-in addresses.
- Developer tools, off by default: the Web Inspector (⌥⌘I) and Safari's Develop
  menu. The inspector relies on undocumented WebKit internals and may stop
  working after a macOS update.

## Importing

- Firefox and Safari open tabs preview first, then reopen in the destination
  profile. Firefox pinned tabs stay pinned; Safari tabs come across unpinned.
  Pages already open are skipped, and private windows open nothing. Chromium
  sessions are not supported.
- Firefox passwords import without a Primary Password. A set Primary Password,
  legacy key3.db profiles, and unknown encryption are reported as unsupported.
  Nothing is guessed.
- Password CSV import no longer reads any browser key, and it reminds you to
  delete the unencrypted export afterwards.

## Finding and reopening pages

- Page text index, off by default: stores up to 4 KB of readable text per page
  in an unencrypted index inside your profile database. Private windows, locked
  spaces, separate-data spaces, and pages with credentials are never indexed.
  Clear it in Settings → Privacy.
- Resume topics on the new-tab page group recent indexed pages. One click
  reopens a topic. Grouping uses on-device language models and falls back to
  plain terms.
- Address-bar suggestions are ranked by relevance, visit count, and recency,
  one row per page. Quick answers handle arithmetic, percentages, and unit
  conversions.
- The command palette has print, find in page, Reader mode, and hide element,
  a preview pane for the highlighted tab, and visible key hints.

## Mac integration, off by default

- Spotlight adds each bookmark's title and address, and nothing else. Bookmarks
  saved from private, locked, or separate-data windows are never added. Turning
  the option off removes everything Browsemium added.
- Handoff offers the active page's https address to your other devices. Only
  ordinary, unlocked windows offer it.
- Shortcuts actions, `browsemium://` links, and `browsemium-ctl` can open a
  page, search, or switch space, and nothing else.

## AI

- The AI dock has a readable API-key field, a connection card, and one composer
  with attachment and skill menus. API messages still need your review before
  they are sent.
- Replies recover. An empty reply shows a retry instead of spinning, and a
  stalled request stops after two minutes. Gemini handles more response shapes.
- Apple Intelligence works as a local provider on macOS 26 and later. It needs
  no key, and nothing leaves the Mac.
- External agent, opt-in and off by default: an MCP endpoint on 127.0.0.1,
  guarded by a token stored in your keychain. An agent has to ask for a task,
  and you approve it on a card that lists the sites and limits. Every click and
  typed value needs your confirmation. Take over (Option-Command-P) pauses the
  agent. Stop (Option-Command-period) ends the task. Pages stay open.
- Page tools (WebMCP), experimental and off by default: a site's registered
  tools can be listed and called inside an approved task. Each call asks you
  first and shows the exact arguments. WebKit has formally opposed the WebMCP
  draft.

## Interface and accessibility

- Chrome text meets 4.5:1 contrast in light and dark, measured by tests.
  Increase Contrast uses stronger text and borders.
- Animation calls in the app honour Reduce Motion, and Reduce Transparency
  turns the glass overlays solid.
- New: a compact toolbar option, a hover-revealed sidebar rail (Control-Command-S
  shows or hides the sidebar), pinned tabs in a grid, a space switcher, and a
  new-tab page with search and "Pick up where you left off".
- Settings has a search field and sections. Its icon buttons and key fields
  have names for VoiceOver.
- VoiceOver users can close a tab from the tab's actions.
- Filter lists: add a local UTF-8 list or an HTTPS address, up to 4 MiB. A list
  takes effect only after it compiles. The shield reports list sizes, never
  blocked-request counts. Rule support is a limited hostname subset, not full
  ABP or AdGuard syntax.

## Known limits

- You cannot reach tab rows with the keyboard alone yet. Use Control-Tab,
  Command-1 through Command-9, or the View menu.
- There is no AppleScript support yet.
- Spotlight, Handoff, page tools, and the external agent have not been tried
  against a second device, a live MCP client, or live sites.
- Not yet checked by hand: a VoiceOver walk-through, keyboard-only use, Increase
  Contrast inside the app, and real Firefox profiles.
